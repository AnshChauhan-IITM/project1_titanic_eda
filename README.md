# Titanic Data Analysis

## Overview
In this project, I worked on the Titanic dataset to understand what factors affected passenger survival. The goal was to explore the data and find meaningful patterns.

## Tools Used
- Python (Pandas, Matplotlib, Seaborn)
- Power BI

## What I Did
- Cleaned the data by handling missing values
- Created new features like FamilySize, IsAlone, and Title
- Explored the data using graphs and visualizations
- Built a Power BI dashboard to present key findings

## Key Insights
- Female passengers had a much higher survival rate compared to males
- Passengers in first class were more likely to survive
- Most passengers were from third class
- People traveling with small families had better survival chances

## Conclusion
This project helped me understand how to clean data, create useful features, and extract meaningful insights from it.
